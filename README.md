# 🦷 Care Contact — Challenge FIAP x Care Plus

## 📋 Sobre o Projeto

O **Care Contact** é uma solução digital desenvolvida como resposta ao Challenge proposto pela **Care Plus (Part of Bupa)** em parceria com a **FIAP**, com o objetivo de **reduzir o no-show nas clínicas da Care Plus**.

A solução utiliza **gamificação, notificações inteligentes e uma interface moderna e intuitiva** para engajar os pacientes, incentivando o comparecimento às consultas e promovendo uma cultura de responsabilidade com a própria saúde.

---

## 🚀 Funcionalidades

- 🔐 Login com CPF e senha
- 📅 Dashboard com próximas consultas
- ✅ Confirmar consulta
- ⚠️ Reagendar consulta
- ⛔ Cancelar consulta
- 🗓️ Calendário de agendamentos
- ⭐ Smile Points — sistema de gamificação e recompensas
- 👤 Perfil do paciente

---

## 🎯 Problema Resolvido

O no-show em clínicas médicas gera desperdício de recursos e prejudica outros pacientes. O Care Contact resolve isso através de:

- Lembretes e notificações inteligentes
- Sistema de pontos e recompensas (Smile Points)
- Reagendamento facilitado com UX fluida
- Interface inspirada em apps modernos como Google Calendar e Duolingo

## ▶️ Como Executar

1. Clone o repositório:
```bash
git clone https://github.com/daher-schmidt/Challenge-Care-Plus---Sprint-2.git
```

2. Abra a pasta no **VS Code**

3. Clique com o botão direito no `index.html` e selecione **"Open with Live Server"**

4. Acesse `http://127.0.0.1:5500` no navegador

> ⚠️ É necessário usar o **Live Server** para que o JavaScript funcione corretamente.
